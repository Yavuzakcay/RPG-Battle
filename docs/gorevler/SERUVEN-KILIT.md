# Serüven KİLİDİ (2026-11-05) — AKTİF

- Şehir görünümü K44, 12 yerleşim görseli/düğümü, Liman, Beyaz Şehir taverna/demirci.
- Canlandırma hizmeti, Knock/kilitli kapılar, Serüven içi hikâye (Celestial, Kefaret).
- Kara Malek, Ejderha görevi, Kraken/deniz paketi, Hapishane olayları, Saklı Cennet, Kemik Adası, yol üstü olaylar, batı adaları.
- K49 sonrası yeni dünya haritası düzeltmeleri, etiketler, Gemini görselleri, yürüme sprite'ları.
- Boss listelerinin bağlanması, Volkan seferi bağları, Derinlikler girişleri.
