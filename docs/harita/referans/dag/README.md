# Dağ (`dag`): kaynak referanslar

Klasik dağ geçidi (yaz, kış).

Izgara önizlemeleri `docs/harita/onizleme/`, Gemini prompt'ları `docs/harita/prompt/` (`npm run harita-referans`).
