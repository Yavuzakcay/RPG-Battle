# Kanat sprite'ları (Kuyruk AS1c)

Savaş jetonunun ARKASINDA çizilen kanat katmanı. Eşleme `data/kanat-esleme.json`; dosya `dosya: null` iken katman sessizce yok.

Üç slot: `tiefling-kanatli`, `celestial-kirik-kanat`, `dragonborn` (10 renk filtresiyle).

Şart: kare (jeton kutusu oranında), şeffaf PNG ya da WebP, kanat BEYAZ tabanlı (renk `filtre`/`renkFiltreleri` CSS filter ile verilir). `dosya` = açık (süzülürken/uçarken), isteğe bağlı `dosyaKapali` = havada değilken. Dosyayı bu klasöre koyup adını eşlemeye yaz. Yer tutucu sprite üretilmez.
