# Hapishane Adası (`hapishane`): üretilen görseller

**Elle düzenlenmez:** bu klasördeki `.webp` dosyaları `harita/hapishane/gorsel/<ad>.jpg` (ya da `assets-ham/harita/hapishane/`) kaynaklarından `npm run harita-gorsel -- <kimlik>` ile üretilir. Kaynak yoksa mevcut görsel korunur.

- `hapishane-dis-halka`
- `hapishane-hucre-platformu`
- `hapishane-iskele`
- `hapishane-mudur-kulesi`
