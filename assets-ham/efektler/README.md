# Efekt sprite'ları (ham)

Hasar efekti sprite'larının ham görselleri buraya konur (Görev D ek parça): `burn.jpg`, `poison.jpg`, `freeze.jpg`,
`acid.jpg`, `bleed.jpg`. İşleme betiği (`npm run efektler`, henüz yazılmadı; ham görseller bekleniyor) buradan
okuyup çıktıları `public/efektler/` altına yazar. `assets-ham/` build çıktısına girmez (Vite yalnızca `public/`'i kopyalar).
