# Efekt sprite'ları (ham)

Hasar efekti sprite'larının ham görselleri (Gemini üretimi): `burn.jpg` (8 kare), `poison.jpg`, `freeze.jpg`, `acid.jpg`,
`bleed.jpg` (6'şar kare). `npm run efektler` buradan okuyup `public/efektler/*.webp` ve `data/efekt-sprites.json` üretir.
`assets-ham/` build çıktısına girmez (Vite yalnızca `public/`'i kopyalar).
